# Virtualis Agent

The Virtualis agent is a pure-Go daemon with no frontend. It runs on each node, detects the installed virtualization drivers, creates and manages instances, collects resource and network metrics, and serves a token-protected RPC interface for the Virtualis master.

Supported drivers: **LXC**, **Incus**, and **QEMU**. QEMU instances get VNC, proxied by the master into a browser noVNC console. Fractional CPU limits (e.g. 0.25 cores) are enforced with cgroup bandwidth (`cpu_milli`); containers get an lxcfs-backed view of `/proc` and the CPU topology, and new instances can use dedicated per-instance disk pools for real quotas.

If the agent sits behind NAT or has multiple network interfaces, explicitly advertise the address the master should use:

```bash
sudo ./virtualis-agent --master http://MASTER_IP:8080 --token <token> --name node-01 --advertise http://AGENT_IP:8081
```

## One-line install

Packages are served by the master's `agent-packages` endpoint. You can also run the install command generated by the master:

```bash
curl -fsSL http://MASTER:8080/api/agent/install.sh | bash -s -- --master http://MASTER:8080 --token TOKEN --name node-01 --mode 1
```

Install modes: `1` agent only, `2` Incus, `3` LXC, `4` QEMU.

## Building from source

```bash
go build -trimpath -ldflags "-s -w" -o virtualis-agent ./cmd/agent
```

Cross-compilation for all supported platforms is handled by the release workflow (`CGO_ENABLED=0`, linux/darwin/windows binaries attached to each GitHub release).
